# Project 3 – Risk Parity & Volatility Targeting Portfolio

## Objective
Build a diversified multi-asset portfolio where each asset contributes approximately equal risk, rather than equal capital.

## Assets
- SPY – US Equities
- TLT – Long-Term US Bonds
- IEF – Intermediate US Bonds
- GLD – Gold

## Methodology
1. Download daily price data using Yahoo Finance
2. Compute daily returns
3. Estimate rolling volatility (63-day window)
4. Construct inverse-volatility (risk parity) weights
5. Compute portfolio returns
6. Compare against an equal-weight benchmark
7. Analyze risk contributions
8. Apply volatility targeting to stabilize portfolio risk

## Key Concepts Demonstrated
- Risk parity allocation
- Rolling covariance estimation
- Marginal and total risk contribution
- Volatility targeting
- Portfolio-level performance analysis

## Results Summary
- Risk contributions are more balanced than equal-weight portfolios
- Volatility targeting reduces drawdowns
- Risk-adjusted performance improves relative to benchmark
